# Сайт-визитка команды — дизайн

## Цель
Сайт команды разработчиков, главный акцент — кейсы в формате лонгрида
(«задача → сложности → решение → результат»), по мотивам KTS / evrone.

## Решения
- **Стек:** Astro (статическая сборка), кейсы — Markdown в `src/content/cases`.
- **Стиль:** плоский, на тонких линиях; Onest (кириллица) + JetBrains Mono для служебного
  текста; тёмная/светлая тема с переключателем и сохранением в localStorage.
  Стекло, шум и glow убраны после дизайн-аудита 2026-10-06.
- **Название команды:** заглушка в `src/config.ts` (одно место для замены),
  там же контакты.
- **Без бэкенда:** контакты — Telegram и почта ссылками.

## Страницы
**Главная (`/`):** Hero (заголовок + список последних проектов с метрикой) →
Направления (таблица, у каждого ссылка на кейс) → Кейсы → Как работаем → Контакты → футер.

**Кейс (`/cases/<slug>/`):** Hero (клиент, заголовок, лид, теги) + 3–4 метрики →
тело Markdown (Задача / Архитектура / Результат) → блок «Сложности»
(нумерованные карточки «проблема → решение» из frontmatter) → стек → следующий кейс.

## Модель кейса (frontmatter)
`title, client, summary, year, duration, order, visual (web|kiosk|vpn|scheduler),
tags[], stack[], metrics[{value,label}], challenges[{title, problem, solution}]`

## Кейсы (вымышленные)
1. Сайт и онлайн-запись для многопрофильной больницы (MedSite).
2. Кассы самообслуживания на Avalonia (avalonia-kiosk).
3. VPN-сервис с клиентами под все платформы (VPN).
4. «Поток» — планировщик задач для команд (Task-Scheduler).

## Проверка
`npm run build` без ошибок; ручной просмотр главной и страницы кейса
в обеих темах на десктопе и на ширине 375px.
